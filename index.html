autonomy-sim: a robot that maps the unknown

A mobile robot dropped into a map it has never seen. A 120-beam LiDAR feeds a log-odds occupancy grid, A* replans on an inflated 8-connected grid every time a new obstacle cuts the path, and a pure pursuit controller turns the plan into wheel commands. Goal reached in 44 s, 36 replans, 2.5 ms median plan time.
