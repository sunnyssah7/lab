# lab

Personal site of **Sandeep Sah**: EE @ UC Riverside, building toward edge AI, robotics and intelligent hardware.

One hand-written HTML file with no framework and no build step. The animations are vanilla JS on `<canvas>`: a procedurally routed PCB-trace field that reacts to the cursor, a LiDAR sweep, a traffic sim and a force-free node graph. It respects `prefers-reduced-motion`.

To edit your details, change the `CONFIG` block at the top of the `<script>`.
